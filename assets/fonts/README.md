# Noto Sans SC

Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

`NotoSansSC-Regular.ttf` is the unmodified upstream `NotoSansSC[wght].ttf`, stored under the UI asset path agreed by this project. It is a variable TrueType font, not a separately generated static instance. UI should rasterize only the characters it needs.
