# Wikipedia 现代麻将牌皮肤 — 素材来源与授权

## 来源
- 词条页：<https://zh.wikipedia.org/wiki/麻将>
- 原始文件：Wikimedia Commons 上的现代麻将单牌插画系列（同风格成套）
  - `MJt1-.svg ~ MJt9-.svg`（筒）→ `pin1..9.png`
  - `MJs1-.svg ~ MJs9-.svg`（索）→ `sou1..9.png`
  - `MJw1-.svg ~ MJw9-.svg`（万）→ `man1..9.png`
  - `MJf1-.svg ~ MJf4-.svg`（风·东南西北）→ `wind1..4.png`
  - `MJd3/MJd2/MJd1`（白/發/中）→ `dragon1/2/3.png`（注意 Commons 序为 中/發/白，与本游戏 DRAGON rank 白=1/發=2/中=3 相反，下载时已按需对调）
  - `MJw5r-/MJt5r-/MJs5r-`（赤五万/赤五筒/赤五索，关东三张制）→ `man5r.png / pin5r.png / sou5r.png`
  例如：<https://commons.wikimedia.org/wiki/File:MJt1-.svg>
- 本目录中的 PNG 为上述 SVG 经 Wikimedia 缩放服务以宽度 160px 栅格化后下载所得，未做二次修改。
- 命名勘误记录：`MJh*`（花牌系列）与 `MJe*`（皇牌）不属于本游戏 136 张牌，未使用。
