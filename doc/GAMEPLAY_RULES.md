# 游戏玩法与规则

适用：当前 V5 `rulesetVersion=1`。核对快照 `e074806a39a674b898120c828038efcd1b5c58d7`。这是玩法入口，逐条判定以领域源码、黄金样本和[规则合同](v5-重构/V5-0-RULE-CONTRACT.md)为准；[日麻详细设计](RIICHI_RULES_DESIGN.md)提供牌型、役种、符与支付解释，其中旧摘要与合同不一致时按合同及现有实现核对。

## 游戏目标与基本流程

四人立直麻将，结合开局码牌、三绝技和独立出千点经济。正常局内流程是摸牌、合法千术窗口、弃牌、他家响应；和牌或流局后进入局间结算，再按整场规则连庄、换庄或结束排名。东风战/半庄战规则与当前 UI 可配置入口分开判断。

全桌固定 136 张实体牌，34 类各 4 张。实体 ID `0..135`，类型顺序为万、索、筒、风、三元；三种赤五各一张。手牌、牌山、死山、河及副露之间只允许实体转移或等额交换。

## 麻将规则要点

| 项目 | 当前规则 |
|---|---|
| 和牌形 | 四面子一雀头、七对子、国士无双；必须有役，宝牌不能单独构成和牌资格 |
| 自摸 / 荣和 | 自摸使用真实摸牌；荣和须在合法响应窗口且不振听 |
| 吃 / 碰 | 吃仅限下家与合法数牌顺子；碰使用两张同种手牌响应弃牌；立直后不能吃碰 |
| 杠 | 支持暗杠、加杠、大明杠；校验余山、岭上补牌次数和总杠数；立直后暗杠须保持规定的待牌/拆分结构 |
| 抢杠 | 加杠先开抢杠窗口，无人和牌才完成杠和补牌；当前不实现国士抢暗杠 |
| 立直 | 门前、未立直、至少 1000 点、满足余山和听牌条件；支付 1000 点供托，之后按合法候选摸切或选择自摸/合法暗杠 |
| 双立直 / 一发 | 按首巡及中断事实判定，不因选择固定测试场景就直接赋予 |
| 振听 | 舍张振听、同巡振听、立直振听；振听禁止荣和，自摸资格另行判断 |
| 响应优先级 | 荣和 > 碰/大明杠 > 吃 > Pass；同级按距离头跳，当前不实现双响/三响 |
| 流局与连庄 | 区分荒牌流局、途中流局；按庄家听牌/和牌等事实处理连庄、本场、供托和下一局 |
| 算分 | 合同登记 42 个稳定役种码；役种登记数不表示每个特殊役在所有流程中都可自然触发 |
| 单局 / 整场 | 单局终态不可复活；下一局新状态机、新 roundId；分数、本场、供托与最终排名按整场权威结转 |

具体的役种限制、符、封顶、庄闲自摸/荣和支付、终局与庄家终了，查[日麻规则详细说明](RIICHI_RULES_DESIGN.md)和[规则合同](v5-重构/V5-0-RULE-CONTRACT.md)。不要用“标准日麻应当如此”静默改变已版本化行为。

## 千术公共规则

千术由权威端验证身份、授权、窗口、余额、offer/决策身份及 deadline。成功动作只扣一次费用，选择后续不重复扣费；同请求重放返回原结果，未授权、余额不足或非法请求不能留下状态/账本副作用。费用和预览属于本座位私有数据。

当前默认 LocalHost 配置为初始出千点 120、落汗费用 1、袖里藏花/偷梁换柱各 10、袖里藏花他家回合选择窗口 5 秒。该数值来自 LocalSnapshotFacts；其他宿主/历史规则默认值和测试夹具不能当作当前房间配置。袖/梁规则层要求费用恰好 10，落汗为正数配置。

## 三大绝技

| 千术 | 当前物理效果与信息边界 |
|---|---|
| 落汗 TileMark | 在合法窗口标记本人手中恰好 4 个不同实体；不移动牌。最多 3 组/12 张，具有跨局有效期和清标规则；只有持有人获得对应实体的授权追踪信息 |
| 袖里藏花 SleeveBloom | 本回合在原摸牌与下一候选之间二选一，可保留或等额换牌；他家回合路径在两个活牌山候选中预留一张，于本人下一次普通摸牌交付。候选和费用仅本人可见 |
| 偷梁换柱 BeamSwap | 冻结合法手牌及牌山/死山槽位候选，选择一张非当前摸牌的手牌作等额交换，或保留原状；避开宝牌指示及被锁定/预留的牌。未授权牌山牌面不公开，落汗命中的牌才提供相应预览 |

袖里藏花当前没有把牌放入独立“袖中存牌”容器。袖/梁激活扣费，保留、过期或失效不自动退款；offer 到期按其安全默认选择清理，不能卡住牌局。无事件的合法状态变化应按回执/权威后态验证，不强求每个选择都产生公开牌事件。

详细规则与交互资料：[落汗](tile-mark/DESIGN.md)、[袖里藏花](sleeve-bloom/DESIGN.md)、[偷梁换柱](beam-swap/DESIGN.md)、[版本合同第 7 节](v5-重构/V5-0-RULE-CONTRACT.md)。这些设计资料含 V4 实现名，当前 C# 对应入口在 Domain/Cheat 与 TableRuntime。

## 开局码牌

规则合同包含准备窗口、目标牌型、看破、费用和槽位限制；目标为清一色万/索/筒、大三元、国士、大四喜，目标 30 点、看破 10 点、叠加 40 点、跳过 0 点。看破按合同抵消他人的目标并处理标记，仍保持 136 张守恒。

算法见[码牌算法](../STACKING_ALGORITHM.md)和[牌型重叠矩阵](../TILE_OVERLAP_MATRIX_ALGORITHM.md)。规则/算法已存在不表示当前普通 Unity 菜单已完成全部准备交互，真实 UI 覆盖按[测试矩阵](TESTING.md)确认。
