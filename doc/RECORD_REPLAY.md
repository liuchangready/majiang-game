# 牌局自动记录与回放

## 使用

每局自动记录默认开启，没有玩家关闭选项。从主菜单选择“牌局记录”，选择最近一局开始回放。回放面板支持自动播放/暂停、单步和速度切换；关闭回放返回菜单。记录读取中、空列表和读取失败均在面板显示状态，失败类型同时写入 Unity 日志。

## 记录范围与持久化

当前默认 Unity 产品组合使用进程内 LocalHost。每条已提交的权威牌局事件随 LocalHost 原有存档原子持久化；回放直接读取存档检查点的完整已提交事件历史及其后的事件日志，不重新提交动作、不启动 AI、不运行或重开 deadline。事件序号是存档中原有的房间序号，恢复检查点与命令重试继续沿用原有幂等语义。主菜单最多列出最近 20 个可读本地牌局，日期取存档文件最后写入时间。

存储位于 Unity `Application.persistentDataPath/local` 下的 LocalHost `.save` 存档（整场目录内的轮次存档也会被发现）。不额外复制事件流或维护第二套事件真相。当前稳定本地房间会继续恢复原存档，因此其后续对局仍属于该本地房间记录；删除或覆盖旧存档的策略由 LocalHost 当前生命周期决定。

## 隐私与支持边界

回放投影只输出公开时间线事件和座位；对摸牌只显示动作，不显示牌面。发牌牌面、私有候选、千术私有事实、账本、种子、事件载荷及事件详情不会进入回放 DTO。旧检查点若没有完整提交事件历史，不会作为完整回放展示。记录列表由本地 App 只在其自身 `persistentDataPath/local` 范围读取；目前 LocalHost 是 Unity 默认产品路径。

远端 TableService 目前没有面向玩家的授权近期列表/回放读取 API；它的事件历史用于服务端恢复和对账，本功能不宣称支持远端牌局。存档损坏、不可读或不完整时，列表/回放显示失败并记录诊断日志；读操作不改写存档，也不参与正在进行牌局的权威裁决。

LocalHost API 和 Unity App 源码变更后，Unity 插件 DLL 需按[共享 DLL 构建说明](BUILD_AND_PACKAGE.md#net-编译与共享-dll)从源码重新生成；本次按任务要求没有运行构建或验证，因此当前树内预编译 DLL 尚未同步。
