# Codex 独立验收计划

本文件为验收标准。2026-09-29 最终未过滤测试 185 项全部通过，无失败/错误/跳过；平台构建及真实桌面渲染结果见 [REVIEW.md](REVIEW.md)。原有 80 项为开发前基线，新增缺陷回归曾实际处于 RED，返修后通过。

## 可执行测试分层

1. 当前 API 缺陷回归：`ArchitectureSafetyRegressionTest`，开发前执行，记录真实失败。
2. 纯服务契约测试：A/B 模块交付后，直接测试固定接口与独立预期，不经 UI、不启动 libGDX。
3. 引擎集成：固定牌序、关闭自动 AI、完整 136 张夹具，逐命令比较前后快照/事件/物理位置。
4. 会话边界：FakeGameSession 驱动 UI；真实 LocalGameSession 验证投影与事件权限。
5. 系统回归：固定种子的 Basic/Trivial 混合整局，多轮完整对局，加桌面编译和 Android APK 构建。

## 固定数值样例

输入 scores=[25000,25000,25000,25000]、dealer=0、honba=2、riichiSticks=3（供托是额外已有场上资金）：

- 闲家 1 荣和玩家 2，30 符 3 翻：基础 3900，放铳者 -4500，赢家 +7500，供托从 3 到 0；newScores=[25000,32500,20500,25000]。
- 闲家 1 自摸 30 符 3 翻：基础付款庄家 2000、闲家各 1000；本场各 +200；deltas=[-2200,7600,-1200,-1200]。
- 庄家 0 自摸 30 符 3 翻：基础每家 2000；deltas=[9600,-2200,-2200,-2200]。
- 一人听牌（玩家 1）：deltas=[-1000,3000,-1000,-1000]，供托仍为 3。

## 测试纪律

- 集成夹具必须分配完整的 136 张，不得 `initializeAll(HAND)` 加零散手牌伪造守恒。
- 测试不能用生产审计作为唯一判断；独立枚举物理区域和资金。
- 不能通过禁用 Basic AI、禁用副露、跳过测试使结果变绿。
- UI API 迁移由 Codex 改测试，保留原有行为断言，并用可注入会话替代公开可变状态。
- 最终命令：`:core:test --rerun-tasks`、`:lwjgl3:classes`、`:android:assembleDebug`。真机视觉/触摸验收另记，不以无头测试代替。
