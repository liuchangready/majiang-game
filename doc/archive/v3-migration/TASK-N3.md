# N3: Actual async transport, room authority lifecycle and deadlock fixes

Own client/network/*.kt (not protocol/**), server/src/main/** only. N2 owns protocol and adding protocolVersion field default3; factories still source compatible. Production core sources about to migrate engine. No tests/UI/engine changes. N completed but review found:

1. ClientTransport imports nonexistent NetworkMessages object. ServerRoom imports nonexistent access.PlayerDecision (actual application.PlayerDecision). startSession parameter is seat, not adminSeat. Read actual APIs and fix compile calls.
2. sendRequest does blocking socket write/flush in CALLER thread! Implement bounded writer queue/thread so UI call returns future immediately; reject overflow/closed/races, per-request deadlines and heartbeat/read timeout. pendingRequests concurrent close/send race cannot leave hung future. Duplicate requestId must not overwrite outstanding future. Malformed response must close/fail pending, not be swallowed indefinitely. close invokes disconnect listeners for EOF/error too, not only PUSH_DISCONNECT.
3. Deadlock: ServerRoom.resume/start/etc holds synchronized(room) then enters host lock; host ticker holds host lock then onSeatUpdate synchronizes(room). Remove lock inversion: event callback must read an atomic/volatile per-seat active connection without room monitor, enqueue only. Queue-full/close callback cannot synchronously call room/host while host publishes; arrange safe asynchronous teardown. Review all lifecycle lock orders.
4. Server currently only compares token, not current connection identity/generation. Verify activeConnections[seat] === conn && generation matches at command execution, reject displaced connections. Displaced flag set before oldclose, new active binding established safely. Prevent already bound connection creating/joining another room and leaking original identity. start freeze once only on actual accepted start; catch failures and structured response, no silent hanging futures when .thenAccept fails.
5. Server uses direct host methods without registered endpoint: requestControl(false) requires live bound identity and may reject. Create/track host.connect(seat) SessionAccess for each occupied connection and submit through it. Fill truly unoccupied seats with host trusted takeover at start; do not allow client arbitraryseat. On reconnect retain takeover until explicit requestControl(false) (taskN originally auto-reclaimed but V3 says explicit reclaim). Bind new endpoint before closing old; oldclose must not disconnect new.
6. Old NetworkSessionAccess round binding must not return current new hand with old roundId; use archived result or exceptional snapshot. Endpoints close releases subscriptions, signals dead transport state; GameClient/UI need ability to see disconnection honestly. Add optional SessionAccess compatible connection status via existing closed field or network accessor, describe API; do not modify engine interfaces without handoff.
7. Client callbacks must not block reader waiting a future or silently swallow event parse errors. Resumption handshake cannot drop initial push before listener; GameClient subscribe+snapshot is sufficient if snapshot obtained after subscription. Session receipt REJECTED should remain ActionReceipt, not throw just because success=false and receipt present.
8. Room limits/timeouts sensible, close pending sessions/acceptor/ticker/executors; no infinite server room leaks on repeated create. LAN-only cleartext scope. Fix server run docs executable classpath (thin jar alone insufficient); Gradle run primary command.

Codex loopback tests enforce privacy, illegal submission, idempotency, reconnect/replacement, malformed frame rejection and pending completion. Deliver N3 with exact APIs, no claim tests run.
