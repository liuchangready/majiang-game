## 测试方法

使用已有 `TestTableBuilder` 建立完整 136 张实体牌桌，通过 `TableAuthority` 提交落汗和普通动作；手动单调时钟控制截止边界，不使用真实睡眠。费用、积分、实体位置、回合、版本和事件分别记录操作前后值，避免“只要返回成功就通过”。

生命周期测试通过实际发牌与合法终局推进，不能直接把到期计数写成预期值。需要定制牌山时使用已有测试装配入口，不给生产代码新增绕过验证的测试后门。隐私测试分别查询四座位及公开投影，核对可见 ID、位置与字段；检查领域行为后，在 API 阶段补线路序列化隔离测试。
