# 开局准备图的生成记录

使用内置 imagegen，基于既有翡翠/朱红/暖金牌桌图连续生成三种状态，未制作浏览器 Demo。

1. **桌边开局选项**：16:9 正式游戏 UI；大部分区域为尚未发牌的麻将桌、四席公开分数与局次；右侧约 320px 紧凑面板，偷天换日 30 点入口、看破 10 点独立勾选、默认零费用开始；不得在初始界面出现六种目标，不生成手牌/弃牌/已生成牌山。
2. **按需牌型抽屉**：保持同场景，用户点偷天换日后右侧局部展开，两列三行显示六个现有枚举目标；仅选择一个，金框勾选；看破可叠加，底部确认施术与零费用直接开局；桌面仍可见。修订后的短句为“影响起手及后续摸牌，不保证成型”，看破短句为“抵消对手本局码牌，费用照付”。完整版效果（含既有落汗）以 DESIGN.md 为准。
3. **本人确认后**：相同空桌背景、右侧更紧凑的“方案已确认 / 不使用千术 · 0点 / 等待其他玩家完成准备”；不显示其他席位的确认数量或私有选择，不要求固定等待。移除玩家界面的“服务端”术语，底部改为“准备完成后发牌”。

`02-target-picker-final.png` 与 `03-confirmed-wait-final.png` 是采用的文字修订版，未带 final 后缀的同名图是中间草稿。图片文字、点数、倒计时和示意牌不可当成真实运行数据；界面实现使用 BitmapFont 和真实快照动态绘制，不把整张图铺成点击底图。
