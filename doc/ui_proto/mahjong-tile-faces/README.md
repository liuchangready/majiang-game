# 麻将牌四面 PNG

牌体比例：宽 34 × 高 54 × 厚 24。PNG 使用透明背景，像素比例为 10 px/尺寸单位。

- `tile-front.png`：正面白色牌芯，340 × 540。
- `tile-back.png`：背面黄色牌背，340 × 540。
- `tile-side.png`：侧面，240 × 540；沿厚度方向前 12 为白色、后 12 为黄色。
- `tile-bottom.png`：底面，340 × 240；沿厚度方向前 12 为白色、后 12 为黄色。

同名 SVG 是 PNG 的可编辑矢量源。侧面与底面的白黄分界位置一致，便于后续按四个面组合成有厚度的麻将牌。
