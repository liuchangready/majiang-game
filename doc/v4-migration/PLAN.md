## 阶段验收

指定开发者必须报告具体修改文件、行为变化和未完成项，不得声称未运行的测试通过。Codex 编译受影响源集、执行相关验收和全量 test、构建桌面与 Android，失败需返修，不能只更新通过数字。

- R1：原有测试恢复；原独立 9 项及新增控制语义、乱序重试、身份隔离等行为回归全绿，最终数量以实测 XML 为准。
- R2：协议往返、按座投影、136 张物理牌与完整结算保真；三层类型不泄漏。
- R3：假时钟/传输覆盖重连和乱序；真实 UDP 断线恢复；通知不能污染新连接。
- R4：调用方不等待权威锁；同桌竞争动作仅一次生效，AI/超时/控制串行；两种绑定业务契约一致。
- R5：默认产品只走 V4，菜单可进入单机和 UDP；码牌、听牌、立直、副露、计时、结算、终局与重连 UI 保真，真实 GL 检查。
- R6：engine 不含连接/传输，protocol 不依赖 engine，client 不依赖 engine/server 实现，展示只依赖 client.api；无旧链引用、全量零失败且无跳过掩盖迁移。
