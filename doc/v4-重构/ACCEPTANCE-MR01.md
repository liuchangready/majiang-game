# MR-01：客户端绑定隔离与恢复验收

验收日期：2026-10-14。开发：Anti；独立测试及检视：Codex。
开发起点：`d8751f19ebe66bc201bf85a90fbc93e779504b2f`。

## 实施结果

- 玩家推送捕获绑定代次、房间、会话、同步代次和座位身份；推进序列器前及各监听器调用前验证身份，换房、换角色或关闭后的旧数据不能继续派发。
- 早期推送缓冲上限为 64；溢出后请求明确的完整基线，合并重复恢复请求。旧恢复响应不能回退新基线，恢复失败允许下一次推送触发重试。
- 恢复快照在验证身份后统一采纳，避免请求路径提前推进游标；有效完整推送可解除等待并继续处理后续游标。
- 网络请求和监听器回调在状态锁外执行。跨角色切换统一双锁顺序；清理待处理队列与清理快照分离，重连握手期间保留最后可见快照。
- 观战握手先处理合法的有界早期缓冲，再按当前基线恢复。
