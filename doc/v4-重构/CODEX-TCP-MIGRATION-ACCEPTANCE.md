## 保留项与后续验收

设计 T4 要求的跨物理网络长连/弱网、玩家与观战各至少 3 次真实中断后的应用资源回落，以及 Android 真机或模拟器建连和后台恢复，当前环境无法执行，**仍为未验证项**。发布到依赖这些场景的环境前须另行实测、记录结果并处理发现的问题。回环测试、构建与桌面快照不充当这些测试的通过证据。

此外，客户端终态派发使用有界执行器和 256 项溢出缓冲；以后若增加 Selector 线程终态动作类别，应重新核对容量上界。
