## 2. V4 提取器：真实入口与确定性策略

提取器直接运行 V4 生产类，而不是静态抄断言：

- `TableAuthority.submitAiChoice(seat, roundId, decisionId, controlEpoch, action, now)`：真实权威提交入口，包含 round/decision/epoch/timing/deadline/candidate 六类校验。
- `TableAuthority.buildAiSeatSnapshot(1, now)`：真实按席位投影。
- `DecisionClock.expired(now)`：真实 deadline 边界查询。
- `TestTableBuilder.create(...)`：test-fixture 构造完整 136 张物理牌桌；`assertPhysical` 在接收后复验。

确定性策略 `DeterministicDiscardStrategy` 只接收：

- `PlayerView`（本席暗牌、本席摸牌、公开牌河/副露/Dora/分数/场况）；
- 本席 `List<GameAction>` 合法候选。

策略按 `tileId` 最小选择 `DiscardTile`，不读取 `GameState`、牌山顺序、他家暗牌、时钟或随机源。提取器记录 `view.legalActions == decision.options.map { it.action }`，并在接收后断言 136 张物理守恒。

固定时间控制：base 3,000ms + reserve 20,000ms，scope ROUND；`opensAt=1000`，`deadline=24000`。所有时间/ID 都来自实际运行并写入 fixture，不在 C# 读取墙钟或随机。

## 3. 7 个 case 与 V4/V5 语义映射

V4 只有一个合并拒绝码 `STALE_AI_SUBMISSION`；V5 分离为 `StaleRound/StaleDecision/StaleEpoch/IllegalAction/DeadlineExpired`。下表是**显式设计映射**，不是声称 V4 已有同名错误码。

| case | V4 实际调用差异 | V4 实际结果 | fixture 的 V5 expected | 映射依据 |
|---|---|---|---|---|
| `AI-001-legal-intent-before-deadline` | `now=deadline-1=23999` | **APPLIED**，1 个 `TileDiscarded` 事件 | `accepted=true, code=None` | V4 严格 `now < deadline` 接受；V5 同边界接受 |
| `AI-002-old-round` | 只把 `roundId` 换成 `stale-round-*` | **REJECTED / STALE_AI_SUBMISSION**，0 事件、0 状态变化 | `accepted=false, code=StaleRound` | V4 先比 round，V5 报告 round mismatch |
| `AI-003-old-decision` | 只把 `decisionId` 换成 `stale-decision-*` | **REJECTED / STALE_AI_SUBMISSION** | `accepted=false, code=StaleDecision` | V4 决策/timing key 不匹配；V5 报告 superseded decision |
| `AI-004-old-epoch` | 只把 `controlEpoch` +1 | **REJECTED / STALE_AI_SUBMISSION** | `accepted=false, code=StaleEpoch` | V4 epoch 不匹配；V5 报告控制代次过期 |
| `AI-005-wrong-seat` | `seat=0` 提交 seat 1 的决策/动作 | **REJECTED / STALE_AI_SUBMISSION** | `accepted=false, code=StaleDecision` | V4 按提交 seat 取当前决策并因身份不匹配拒绝；V5 报告 seat/decision 身份不匹配 |
| `AI-006-candidate-not-legal` | 提交 `Pass(1)`，不在 DISCARD 候选 | **REJECTED / STALE_AI_SUBMISSION** | `accepted=false, code=IllegalAction` | V4 候选列表校验失败；V5 分离为 authority 侧 IllegalAction |
| `AI-007-exact-deadline` | `now=deadline=24000` | **REJECTED / STALE_AI_SUBMISSION** | `accepted=false, code=DeadlineExpired` | V4 要求严格早于 deadline；V5 报告截止过期 |

`AI-006` 的构造差异必须明说：C# `CommandIntent` 拒绝构造“自身 observation 之外”的动作，因此 C# 侧保留已记录动作在 frozen observation 中合法、但在 fresh `AiAuthoritySnapshot` 候选列表中移除；两边都命中 authority 侧“动作不再是当前合法候选”的检查，而不是声称 C# 能构造非法 intent。

deadline 边界另外记录为真实 `DecisionClock` 查询：

- `expiredAtDeadlineMinus1=false`
- `expiredAtDeadline=true`
