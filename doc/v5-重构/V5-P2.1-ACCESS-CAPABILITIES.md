可复核的 V4 事实：

1. 默认 `protocolVersion=3`；V4 真实端点构造使用业务版本 8（`TcpRequestRouter.kt`、`SharedRoom.kt` 均显式传入）。3 和 8 都不是 V5 版本。

6. 默认 `resumption=true`，`remoteTransport/persistence=false`；三个布尔位互不联动。
7. `null` 由 Kotlin 非空参数检查拒绝；`protocolVersion=0` 与空集由 `require` 拒绝。

## 3. V5 契约语义

实现：`dotnet/src/Mahjong.Contracts/AccessCapabilities.cs`（`Mahjong.Contracts`，`netstandard2.1`，C# 9）。只依赖 BCL，不依赖 Domain/Wire/Client/服务端。

### 3.1 协议版本

- 构造函数只接受 `ProtocolVersion.Current`，即 `ProtocolConstants.Major=1`、`Minor=0` 的 `1.0`。
- 明确拒绝：`default(ProtocolVersion)` 的 `0.0`、未来 major `2.0`、V4 默认 `3.0`、V4 真实业务版本 `8.0`、非冻结 minor `1.1`。异常为 `ArgumentOutOfRangeException`，`ParamName=protocolVersion`。
- 没有把 3 搬进 V5 默认，也没有把 V4 的 3/8 当作 V5 协商结果。minor 更高可选字段的协商仍属于 `ProtocolCompatibility` 的 HELLO/WELCOME 逻辑，不由本能力类型表达。

### 3.2 支持人数与四人产品范围

- 默认/常量：`CurrentPlayerCount = ProtocolConstants.MaxSeat + 1 = 4`。
- 输入必须是 1..4 的整数，重复值去重，保留首次出现顺序；空集、0、负数、>4 均明确拒绝。
- 契约形状保留“支持人数集合”，但**当前 V5 四人产品只声明 `{4}`**。三人麻将仍属 V5 架构明确排除的产品范围（`V5-ARCHITECTURE-DESIGN.md` §2）；类型可表示某个数字，不等于当前系统支持该人数规则，也没有任何当前端点声明 `{3}`。
- 该验证只拒绝协议不可能/无意义的人数，不把未来产品模式实现出来。

### 3.3 布尔能力与真实性

- 三个布尔位相互独立，无联动、无自动升级。
- 默认 `remoteTransport=false`、`persistence=false`、`resumption=false`：本批没有装配任何 V5 端点，不宣称远端/持久化/恢复已完整实现。端点所有者只有在具备真实实现证据时才能显式置 `true`。
- 真实 `false` 原样暴露，不使用“缺字段/隐藏 false/虚报 true”的方式规避矩阵文字。`implementation-v1.json` 的 `gapSummary` 中“不得向客户端暴露 persistence=false”按本次用户复核规则解释为“不得隐藏真实 false 或虚报 true”；本契约保留真实布尔值。
- 默认 `resumption=false` 是相对 V4 默认 `true` 的有意差异：V5 当前没有可验证的端点恢复装配，不能在纯契约默认值上冒充已完成。

### 3.4 不可变、复制与相等

- 构造时把 `IEnumerable<int>` 枚举进私有 `List<int>`，去重后 `ToArray()`，再以 `Array.AsReadOnly` 暴露；输入集合后续变更不影响实例。
- 暴露类型为 `IReadOnlyList<int>`；即使强转 `IList<int>`，`Add/索引赋值/Clear` 都抛 `NotSupportedException`。
- 类为 `sealed`，所有字段只读；没有 `deepCopy()` 方法，因为构造即完成深复制，实例本身不可变。
- 值相等覆盖协议版本、三个布尔位和人数集合；人数按集合比较，忽略声明顺序，重复输入不影响相等；相等对象 hash 一致。
- `ToString()` 输出完整字段，便于证据与日志核对。

## 4. V4 → V5 差异记录

| 维度 | V4 实测 | V5 本契约 | 处理理由 |
|---|---|---|---|
| 默认协议版本 | 3 | 1.0（`ProtocolVersion.Current`） | V4 默认值与真实业务版本 8 均不是 V5；不混用 |
| 版本校验 | 仅 `>=1`，接受 3/8 | 只接受当前 1.0；0/2/3/8/1.1 拒绝 | 防止把 V4 值或未冻结 minor 当 V5 能力 |
| 构造输入复制 | 不复制，外部可变引用可见 | 立即复制，外部变更不可见 | 输入防御复制 |
| 普通实例外部写 | 允许（`LinkedHashSet` 可变） | 只读；强转写入抛异常 | 安全不可变暴露 |
| 深复制 | 手工 `deepCopy()`；`copy()` 共享集合 | 无 `deepCopy()`，构造即快照 | 不可变类型无需可变副本 |
| 空集 | 拒绝 | 拒绝 | 语义一致 |
| 非法人数 | 接受 0/-1/5 | 拒绝 0/负数/>4 | 能力声明不应表达不可能人数 |
| null 人数 | Kotlin NPE | `ArgumentNullException` | 明确参数错误 |
| 默认 resumption | true | false | 无 V5 端点恢复证据，不虚报 |
| 相等 | Set 语义，顺序无关 | 集合语义，顺序无关；含三个布尔位 | 值语义一致并覆盖全部字段 |
