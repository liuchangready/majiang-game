## 5. 实现与根因修复

### 5.1 D-01：真实 sdkmanager/Android CLI 崩溃

历史失败链在本冻结基线上重新复现：Unity 选择 `...\cmdline-tools\latest-23-newcli-backup\bin\sdkmanager.bat --list`，该 23.0 `sdkmanager.bat` 是转发到 `android-cli.exe` 的弃用壳；`android-cli.exe sdk list` 在 Windows 10 19045 上以 `0xC0000409` 结束。

修复：`repair-android-toolchain.ps1` 在任务独占 `build\android-toolchain\private\android-cli\android-cli-sdkmanager16.cmd` 创建**只读发现适配器**：

- 把 Unity 的 `--sdk=... sdk list [--all]` 转发到已安装的官方经典 `cmdline-tools\16.0\bin\sdkmanager.bat --list`；
- stdout/stderr 与 exit code 原样透传，不伪造包列表、不截断错误、不返回 0 绕过；
- `--version`/`--help` 透传；install/update/remove 等变更命令明确拒绝（exit 2），避免写入共享 SDK；
- Unity 只在进程内收到 `ANDROID_CLI_BIN=<适配器>`，共享 `android-cli.exe`、junction、注册表、EditorPrefs、全局 PATH 均未改。

修复后 shim 日志（Unity 实际调用）：

```text
args=--sdk="D:\Unity\Hub\Editor\6000.3.27f1\Editor\Data\PlaybackEngines\AndroidPlayer\SDK" sdk list --all
[shim] list rc=0
```

### 5.2 D-02：真实 Ninja 缺失

修复：从官方 `https://github.com/ninja-build/ninja/releases/download/v1.13.2/ninja-win.zip` 下载，先核验 GitHub release asset digest `sha256:07fc8261...8dc65`，再核验 `ninja.exe` SHA256 `E52A7AD9...F847B8` 与 `ninja --version=1.13.2`，安装到任务独占 `build\android-toolchain\private\ninja\1.13.2\ninja.exe`；仅把该目录加入 Unity/Gradle 子进程 `PATH`。

CMake 3.22.1 与 JDK 17 保持共享只读；本任务没有替换共享 Editor/SDK/JDK，也没有创建 junction。

### 5.3 探针隔离（冻结新增 P4.2 UI 后的必要最小适配）

当前冻结的 Unity 工程新增了 P4.2 UI/App/Table/Spectator asmdef，其 `precompiledReferences` 需要 `Mahjong.Client.dll`；全场景还使用 TextMeshPro。若继续按 P2.2 旧 wrapper 复制整个 `Assets`，会出现：

1. `Mahjong.Client` 缺失导致脚本编译失败；
2. 即使补建冻结 Client 并构建成功，3 条 `[Unity.TextMeshPro] ... Method was given its own cpp file` IL2CPP 警告被 `BuildSummary.totalErrors` 计为 **errors=3**，build 仍 Succeeded，但不满足 `errors=0` 验收。

本任务没有放宽断言，也没有改业务代码；只在**任务独占 TEMP 的 probe 工程**内做最小隔离：

- 只保留 `Assets/Scripts/Platform/WireAotSmoke.cs`（及其 meta）与 Wire 依赖闭包；删除 UI/App/Table/Spectator/Tests 的 temp 副本；
- 把 temp `ProjectSettings/EditorBuildSettings.asset` 固定为 `SampleScene`（探针通过 `RuntimeInitializeOnLoadMethod` 执行，不依赖游戏场景）；
- 物化 tracked 的空目录 meta（如 `Assets/Audio.meta`）对应目录，避免 Unity 重复告警；
- 真实 `unity/Mahjong.Unity` 与所有 tracked 源码均未修改。

因此本 APK 是**精简 Wire AOT 探针**，不是完整游戏 Android 包；报告不把它写成整场端到端通过。
