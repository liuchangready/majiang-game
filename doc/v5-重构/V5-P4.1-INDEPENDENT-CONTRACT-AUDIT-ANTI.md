### D-ANTI-01 [MAJOR] `LocalSave` 增量保存策略未明确最新事实与计时载荷如何持久化，存在冷恢复校验与时序写回缺口
- **严重级别**：MAJOR
- **位置**：`doc/v5-重构/V5-P4.1-CONTRACT-PREPARATION.md` §2.2 行 513–547（`LocalSaveState`），§2.3 行 856–863，§3.1 行 967–968，§3.2 行 991–994
- **复现分析**：
  查阅 [TableDurableContracts.cs:556-591](file:///D:/majiang-wt/p41-independent-audit-anti-20261026/dotnet/src/Mahjong.TableRuntime/TableDurableContracts.cs#L556-L591)、[TableRecoveryService.cs:1120-1166,1286-1312](file:///D:/majiang-wt/p41-independent-audit-anti-20261026/dotnet/src/Mahjong.TableRuntime/TableRecoveryService.cs#L1120-L1166) 与 [InMemoryTableStore.cs:1370](file:///D:/majiang-wt/p41-independent-audit-anti-20261026/dotnet/src/Mahjong.TableRuntime/InMemoryTableStore.cs#L1370)。
- **实际 vs 期望**：
  - **实际**：`TableCheckpoint` 自身已封装完整的 `TimingPayload` 与 `CommittedFactsPayload`。但草案 §2.3（862–863 行）与 §3.2（994 行）允许 `CommandJournal` 与 `EventJournal` 作为 checkpoint 之后的尾部命令存在（即 `stateVersion > checkpoint.StateVersion`）。在冷恢复时：
    1. `TableRecoveryService` 优先读取 `latestFacts = await _store.LoadCommittedFactsAsync(roomId)`，若为空则回退到 `checkpoint.CommittedFactsPayload`（第 1120 行）；重放尾部命令后，执行 `TableVisibilityProjection.ValidateRecoveredFacts`，将重放后的状态与事实快照比对；
    2. `TableRecoveryService` 会调整剩余时间并通过 `_store.AppendTimingAsync` 写回调整后的时序（第 1286 行），后续超时判定依赖 `_store.LoadTimingAsync`。
    草案在增量保存模式下，未说明 `LocalSave` 究竟如何在尾部保存最新的事实快照与时序载荷，导致 `LocalTableStore` 无法确定如何实现 `LoadCommittedFactsAsync` 与 `AppendTimingAsync`，若回退到旧 checkpoint 则在存在出千/鸣牌尾部命令时会导致恢复返回 `TableRecoveryResult.Failed`（状态码 `TableRuntimeReasonCode.RecoveryFailed`）。
  - **期望**：草案必须明确二选一的持久化策略：
    - *策略 A（简化单检查点模型，推荐）*：规定本地单机模式下每次提交均由宿主生成并落盘最新完整 `CheckpointBlob`（即 `checkpoint.StateVersion == stateVersion`），尾部日志仅作审计，`LoadCommittedFactsAsync` 与 `LoadTimingAsync` 直接由最新检查点满足；
    - *策略 B（检查点+增量日志模型）*：在 `LocalSave` 中显式增加 post-checkpoint 的最新 `CommittedFactsPayload` 与 `TimingPayload` 字段，以支持 `AppendTimingAsync` 与独立事实更新。

- **修复要求**：在 §2.2、§2.3 与 §3.2 明确裁决采纳策略 A 或策略 B，补齐 `LocalTableStore` 对 `LoadCommittedFactsAsync`、`LoadTimingAsync` 与 `AppendTimingAsync` 的数据流映射说明。
