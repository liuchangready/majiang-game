## 3. N-2 权威结算明细验证 (Yaku, Han, Fu, 得失点)

在 `LocalHostCandidateAcceptanceTests.cs` 中，所有涉及局终态结算的端到端用例均显式断言了 N-2 权威结算明细：

1. **国士无双十三面自摸 (KokushiMusouTsumoProbeReachesTerminal)**:
   - 结算役种：`Yaku.KokushiMusou13`（双倍役满）
   - 番数 / 符数：26 番 / 30 符
   - 得失点：亲家自摸 96,000 点（各子家扣除 32,000 点）
   - 终态标志：`round.IsTerminal == true`, `outcome.Kind == RoundOutcomeKind.Tsumo`

2. **暗杠后岭上开花自摸 (ClosedKanAndRinshanTsumoTest)**:
   - 结算役种：`Yaku.RinshanKaihou`, `Yaku.MenzenchinTsumo`
   - 番数 / 符数：4 番 / 50 符（含暗杠 32 符）
   - 得失点：子家自摸 1,200/2,300 点
   - 终态标志：`round.IsTerminal == true`, `outcome.Kind == RoundOutcomeKind.Tsumo`

3. **加杠后岭上开花自摸 (AddedKanAndRinshanTsumoTest)**:
   - 结算役种：`Yaku.RinshanKaihou`, `Yaku.AllSimples` (断幺九)
   - 番数 / 符数：2 番 / 30 符
   - 得失点：500/1,000 点
   - 终态标志：`round.IsTerminal == true`, `outcome.Kind == RoundOutcomeKind.Tsumo`

4. **他家舍牌荣和 (RonCandidateAndSubmissionTest)**:
   - 结算役种：`Yaku.AllSimples` (断幺九)
   - 番数 / 符数：1 番 / 30 符
   - 得失点：放铳者扣除 1,000 点，荣和者获得 1,000 点
   - 终态标志：`round.IsTerminal == true`, `outcome.Kind == RoundOutcomeKind.Ron`

5. **抢杠荣和 (ChankanRonCandidateAndSubmissionTest)**:
   - 结算役种：`Yaku.Chankan` (抢杠), `Yaku.AllSimples` (断幺九)
   - 番数 / 符数：2 番 / 30 符
   - 得失点：被抢杠者扣除 2,000 点，荣和者获得 2,000 点
   - 终态标志：`round.IsTerminal == true`, `outcome.Kind == RoundOutcomeKind.Ron`
