## 2. R1 缺陷逐项返修

### D-R1-01（MAJOR）start 独立 owner/in-flight 门

- 新增 `AppRouter._startInFlight`，入口用 `Interlocked.CompareExchange` 原子获取；第二个 `StartLocalGameAsync` 立即返回 `Busy`，**不进入 `OpenLocalSessionAsync`、不 load、不 shutdown**。`finally` 只由成功取得门的 owner 释放。
- `_isTransitioning` 只表示场景过渡，不再包住整个 async open；owner 自己的 `LoadForStartOwnerAsync(Table)` 直接执行，不会被自己的 start 判成 Busy。
- 新增 `SceneLoadOutcome { Loaded, Busy, Failed }` 与公开 `TryLoadAsync`。`LoadAsync` 仍返回 bool 以兼容旧调用，但 owner 路径能区分：`Busy` 直接返回 Busy，绝不调用 `ShutdownAsync("TABLE_SCENE_LOAD_FAILED")` 去关闭别的 owner 会话；只有真实 `Failed` 才做失败清理。
- 新增 `_navigationGeneration`：每次公开 `LoadAsync`/`TryLoadAsync`、`ReturnToMenuAsync` 都递增。open 完成时同时比较 `_currentScene` 与代次；Lobby→Menu→Lobby 或公开同场景 `LoadAsync(Lobby)` 都会使旧 open 失效，返回 `Cancelled` 并清理自己打开的会话，不会晚进 Table。
- 明确支持公开同场景 reload（取消旧代次），不再用反射 `_currentScene` 假造用户路径。

### D-R1-02（MAJOR）终态隔离不再吞成 Cancelled，capability 不再虚假可用

- `AppComposition.SupportsLocalStart` 现在在锁内检查 quitting、shutdown-in-progress、quarantine、`_quarantinedShutdownResult`、coordinator `IsQuarantined` 和 channel factory；终态后为 false。
- 新增有锁公开面：`IsTerminal`、`TerminalResult`、`IsShutdownInProgress`。
- `AppRouter.StartLocalGameAsync` 对 `LocalTableUnavailableException`、`OperationCanceledException`、其他异常都先检查 composition 终态；终态返回 `Terminal/LOCAL_HOST_TERMINAL`，不再伪装正常取消。abandon 的 `ShutdownAsync("OPEN_ABANDONED")` 与 Table load 失败的 cleanup 都检查 `ShutdownResult.Outcome/Quarantined/MenuAllowed`；`CloseFault`/`CloseTimeout`/`PumpBarrierTimeout`/`PumpFault` 进入终态。
- `LobbyPresenter` 对 `Terminal` 设置 `_terminal=true`，按钮 disabled，显示稳定终态码且不显示“可重试”；之后点击直接返回。`Failed` 仅在 `IsLocalGameStartAvailable` 仍为 true 时才提供重试文案。
- `ReturnToMenuAsync` 在 `MenuAllowed=false` 时返回 false，不加载 Menu；`quitting/shutdown` 门拒绝新 start。
- 保留原 quarantine 终态、coordinator/actor 不替换、clean shutdown 可重进。

### D-R1-03（MINOR）Initialize 晚绑定/重复绑定

- `Initialize` 现在无论 Start 前后都会立即 `ApplyLocalGameStartCapability()`；`Start` 加 `_started` 幂等门。
- 重绑 session 时先 `DetachSessionView()`，同一 view 也先 `-=` 再 `+=`，不会累加旧 session 监听。
- `OnSessionChanged` 与所有 UI 写入受 `_destroyed` 门保护；`OnDestroy` 解绑按钮与 session。
