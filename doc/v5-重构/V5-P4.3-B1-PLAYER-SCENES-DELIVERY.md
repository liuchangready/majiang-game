## 1. 任务背景与交付定位

本子包（P4.3-B1）为日式立直麻将与千术对局场景的表现层与输入驱动层，基于已独立验收冻结的 **P4.3-A 纯模型层**（`PlayerTableViewState`、`PlayerTableProjectionMapper`、`TableCommandIntentFactory`、`TableInteractionState`、`ConfirmedAnimationQueue` 五大核心模型及对应 40 项单元测试保持字节完全不变）和已完成释放的 **P4.4 观战与结算表现层**。

### 1.1 明确边界声明与非目标
1. **不替代完整 P4.3 或 G2**：V4 架构仍为生产基线；本子包仅交付可实际加载运行的对局表现与输入场景及测试，不宣称完成完整离线整场对局或 G2 阶段。
2. **不伪造权威事实**：Client 的 `SnapshotChanged` 当前仅提供权威快照，尚未提供 typed visible event 流。本表现层仅依据确认快照差异触发动画，不自创领域事实或修改底层 Client/Wire 获取虚假闭环，后续完整事件流供给保留明确缺口。
3. **未就绪通道不冒充生产**：未接受的 `LocalHost` 权威工厂仍不可用，不将受控测试通道（`PlayModeScriptedTableChannel`）作为真实本地/远端 E2E 生产信道。
4. **状态保留**：181 classified、Android FAIL、iOS BLOCKED、设备跨物理网络实测 NOT_RUN 保持原有标记，不冒称通过。

## 2. 具体交付内容与实现架构

### 2.1 对局场景 (`Assets/Scenes/Table.unity`) 与场景构建器 (`TableSceneBuilder.cs`)
- **真实可加载场景**：通过自动化构建器 `TableSceneBuilder.cs` 生成 `Table.unity`（尺寸 594,435 字节，GUID `b81925e458e10ad45b44a6a58b9bb6ef`），已在 `EditorBuildSettings.asset` 串行登记。
- **UI 布局与多分辨率适配**：
  - 基于 CanvasScaler（1280x720 参考分辨率，ScreenMatchMode.Expand），配合 SafeArea 挂载，适配 16:9（1280x720）与 21:9 超宽屏（2560x1080 包含 140px 左侧刘海安全区）。
  - **四席面板 (`TableSeatView`)**：本席位于底部明牌展示；他席位于东/北/西，严格遵守隐私白名单，仅以数量形式展示占位 `[牌]` 与无身份占位 `[暗杠:4张]`，杜绝任何牌实体 ID、出千暗账、袖牌泄露到他席文本或 GameObject 命名。
  - **牌河与副露**：展示四席真实舍牌（含立直横置标识、摸切标记）与公开副露（吃/碰/大明杠/加杠）。
  - **中央场况与宝牌**：展示公开死山宝牌指示牌、牌山剩余张数、场风、局数、本场棒、立直棒存量、最新舍牌。
  - **本席手牌面板 (`OwnHandPanel`)**：14 张本席手牌槽位与独立摸牌槽位，支持触屏与鼠标点选。
  - **候选动作面板 (`ActionPanel`)**：包含打牌、吃、碰、杠、立直、自摸、荣和、过（Pass）、取消选择等动态交互按钮。
  - **三大绝技面板 (`CheatPanel`)**：准确呈现中文字样“落汗”、“袖里藏花”、“偷梁换柱”及“码牌准备”；包含落汗四张点选弹窗、袖里藏花两张选其一/原牌调换弹窗、偷梁换柱候选牌山死山槽位弹窗、码牌计划配置弹窗。
  - **控制与时钟**：权威倒计时进度条与秒数提示、暂停指示器、重连中指示器、返回大厅与局终结算导航入口。

### 2.2 真实 MonoBehaviour 控制器与命令提交流水线 (`TablePresenter.cs`)
- **生命周期绑定**：实现 `IAppNavigation`、`ISessionView` 与 `ITableCommandSink` 真实装配。
- **命令下发与幂等安全**：
  - 通过 `ITableCommandSink.SubmitAsync` 下发由 `TableCommandIntentFactory` 构建的标准协议命令 `ProtocolCommand`。
  - 维护规范的 `RequestId`、`RequestScopeId`、`controlEpoch`、`decisionId`、`offerId`、`windowId`。
  - 禁止未知结果或双击时生成新 ID 盲目重发；重复点击由 `InteractionState` 拦截并返回 `AlreadyPending`。
  - 未确认前不提前扣费或移动实体牌；确认快照到达后驱动动画队列更新。
- **白名单组件合规**：剔除未在白名单内的 UGUI `Toggle` 脚本，全面复用原生 `Button` + `TextMeshProUGUI` 实现透视开关与选牌交互，严格遵循 Unity 边界安全策略。

### 2.3 组合根装配与会话协调扩展
- **`ITableCommandSink.cs`**：定义对局命令汇聚接口，包含 `CanSubmit`、`Generation` 与异步提交方法。
- **`TableSceneBinding.cs`**：在场景加载后通过 `AppRoot.Instance.Composition` 自动关联 `SessionCoordinator`、`SessionView` 与 `AppRouter`。
- **`ISessionView.cs` & `SessionCoordinator.cs`**：向后兼容透传 `IsFullBaseline` 与 `StreamCursor`，支持全量基线重置与单调游标识别；在 `Shutdown`、`Quarantined` 或 `Generation` 失配时立即阻断命令提交。
- **`AppRouter.cs`**：注册 `SceneId.Table` 与 `OpenTable()` 路由方法。
