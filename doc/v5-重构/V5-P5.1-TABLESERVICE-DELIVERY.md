## 3. 服务概览（新 `Mahjong.TableService`，ASP.NET Core / net8）

入口 `Program.Main`（`Program.cs`）：全部配置 fail-closed 校验后启动；**缺校验密钥/配置非法时拒绝启动**（`ExitBadConfig=2`；`TableKeyConfigurationException` → `ExitNoValidationKeys=3`）。不存在任何 accept-all 模式。组件：

| 文件 | 职责 |
|---|---|
| `TableServiceWebHost.cs` | 上述宿主：`/v1/table?room=` WebSocket 准入端点（drain 503、room id 合同、非 WS → 426）、`/health/live` 200、`/health/ready`（drain 时 503）、`/admin/drain`（未配置 token 即 404 不存在；`X-Admin-Token` 常量比较；`?enabled=true|false`）。**不注册 ForwardedHeaders**：绝不信任任意 `X-Forwarded-*`，TLS 在受控入口终止由运维绑定链路决定 |
| `TableSessionHandler.cs` | 单 WS 会话：V5 帧（一整条 binary message = 一 Envelope，分片累积至 EndOfMessage，有界累计 >`MaxInboundMessageBytes`/早期 >`MaxEarlyBufferBytes` 即拒）、deadline 与 ReceiveAsync 竞速但从不取消挂起的 Receive（保住关闭握手）、HELLO/WELCOME 版本协商（major 不兼容永久拒绝、V4 MJTC 魔数拒绝、拒绝 text/未知首帧/多 Envelope 拼接/空消息）、限速令牌桶、错误/命令信封队列、`SYNC_REQUEST`/回执查询、心跳回显 |
| `TableTicketValidator.cs` | **TableService 自己的只读 ES256/JWKS 验证器**（RFC 7638 JWK thumbprint kid）：header 白名单 `alg/typ/kid`、仅 ES256、载荷白名单 `iss/sub/aud/room_id/assignment_id/role/seat_id/jti/iat/exp/nbf/protocol_major/ruleset_version/projection_version`（未知/重复 claim 拒绝，含 `owner_epoch`）；P1363 签名；`iss/aud` 精确匹配、TTL 上限、时钟偏差、jti 一次性 |
| `TableTicketConsumptionRegistry.cs` | 票据一次性消费端口（默认进程内实现；真实 Lobby 消费/PG 端口留 P5.2/P5.3）
| `TableSessionDirectory.cs` | 会话目录：同账号顶号（旧会话 4403）、跨账号不可顶号、旧票据不可复入 |
| `TableRoomHost.cs` / `InMemoryTableHostRegistry` | **按桌隔离**的真实 actor registry：每房一个 TableRuntime actor + 命令映射 + 广播 sink；平台 tick 驱动着独立于 WS 线程（`RoomTickIntervalMs=250`），心跳不阻塞 actor 规则 deadline |
| `TableCommandMapper.cs` | 已接受命令 envelope → TableRuntime 命令的映射：UI 自带可信 settlement / 篡改 source version / 保留字段合同违约在**进入 actor 前**拒绝；无 authority facts 时保持既有 `AuthorityUnavailable` 拒绝 |
| `TableWireStreaming.cs` | 公开/私有流到 Contracts.Wire 的编码：每座位私有视图只含本座私有字段，**不序列化全域再删字段**；slow-consumer 有界出站与背压断开 |
| `TableProjectionContextSource.cs` | 初始轮投影工厂测试实现（正式 PG 投影到 P5.2） |

## 5. 关闭码（映射自共享 `Contracts.ProtocolErrorCode.ToWebSocketCloseCode`，未新增 Wire/Domain 变更）

| WS close | 语义 |
|---|---|
| 1000 | 正常本地关闭（LOCAL_CLOSED） |
| 1009 | MessageTooLarge（帧/Envelope 超限，截止而不是截断） |
| 4400 | 协议族：text 帧、非 HELLO 首帧、空消息、Envelope 拼接、shape 违约 |
| 4401 | Unauthenticated / InvalidToken / HandshakeTimeout |
| 4403 | DisplacedByNewConnection（同账号顶号）/ RoomClosed |
| 4409 | RequestIdConflict |
| 4429 | ServerBusy（泛洪/RATE_LIMITED，连接级关闭）|
| 4503 | ServerShutdown / LeaseLost（drain/失去租约） |

业务级错误（rate limited / busy / foreign receipt 等以 Envelope ERROR 报告可重试处置）与会话级关闭码分离。
