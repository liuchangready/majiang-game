### 正向用例：`PositiveLocalWssTrustChainCompletesTlsHandshakeAndWireRoundTrip`

对 production `WebSocketTableChannel`（默认路径代码不变）执行真实 loopback TLS 握手 + Wire 信封双向收发：

1. 每测试新建内存 CA（root `CN=Mahjong V5 Loopback Test Root <8hex 随机>`）并由其签发 leaf（SAN：DNS `mahjong-v5-test.local` + IP `127.0.0.1`，EKU serverAuth）。
2. loopback 测试服务器以该 leaf 完成 SslStream TLS 服务端握手；客户端经 production 通道 `OpenAsync` 完成握手（回调内链校验通过）。
3. 客户端 `SendAsync` 合法 Heartbeat Ping 信封（16 hex nonce），服务器以 `WireCodec.Decode` 验证合法性后回 `PlayerUpdate`；客户端 `ReceiveAsync` 并解码断言 cursor。
4. 证据断言：`channel.IsOpen`、`AcceptedConnections==1`、回调 `AcceptedCertificates==1` 且接受指纹 == 本次 CA leaf 指纹、无拒绝记录、服务器 `Errors` 为空。

### 隔离与安全边界（未放宽任何校验）

- 校验器仅在「本次测试客户端实例」上生效：production `ClientWebSocketConnectionFactory` 不持有任何回调，默认 OS 校验由既有负向用例 `SelfSignedWssCertificateIsRejectedByDefaultValidation`（未改动）持续证明。
- 每次校验全部执行：主机名不匹配硬拒（平台 SslPolicyErrors NameMismatch）；当前时间必须落在 leaf 有效窗内；`X509ChainTrustMode.CustomRootTrust` 只信任本测试 root，`VerificationFlags=NoFlag`，链状态必须逐项 `NoError`，并要求 serverAuth EKU。任何不满足即拒绝并记录原因。
- 未改机器证书库、未改全局 TLS 设置、未提供"关闭校验/接受任意证书"开关；revocation `NoCheck` 仅为测试 CA 无 CRL 发布点的通行做法，其余全部从严。
- 探测脚本禁用 `Date.now` 之类约束不适用（本仓库为 xUnit C# 测试）；root/leaf 有效期在 CA 工厂内推导，保证过期负例的 leaf 窗口被 root 窗口覆盖。
