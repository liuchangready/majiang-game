### [B2-R1-BLOCKER-01] 牌墙耗尽后没有 exhaustive-draw 终局转换

**严重级别：BLOCKER**
**位置：** `dotnet/src/Mahjong.TableService/TableDecisionRuntime.cs:260-300`（`AutoAdvanceDrawAsync` 无条件 `RoundCommand.Draw`）；`dotnet/src/Mahjong.Domain/RoundStateMachine.cs:1510-1527`（wall 0 只加 `WallExhausted` 并停在 `Draw`）；`RoundStateMachine.cs:1185-1213`（exhaustive draw 需要 `RoundCommand.ExhaustiveDraw` + `RoundSettlement`）；wire action 词表没有 exhaustive-draw 命令（`ProtocolCommand.cs` `ProtocolActionType`）。
**复现：**

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File build/p54b-b2-readiness/run/run-b2-readiness.ps1 `
  -DurationSeconds 780 -ActionCap 900
# 运行中只读采样（见 §2）
```

**实际：** 70 次打牌/69 次摸牌后 `WallExhausted=1`；`phase=Draw`、`wall=0`、`state_version=88` 冻结；四席 `decision=null`；`sessionFinished=false`；`settlement_outbox=0`；780s 后仍无 terminal。
**期望：** 权威服务在 wall 0 以可信结算事实提交 exhaustive draw，进入 `RoundEnd`，产生 terminal result 与唯一 outbox；不得由客户端声明、不得靠超时/人工改状态。
