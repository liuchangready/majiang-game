# 疯狂动物麻将 · 主菜单分层与入场设计

状态：主菜单专项设计稿。开发范围仅为 `ui_demo` 的主菜单页面与其样式/入口入场动效。全站其余八屏和三种千术原有交互保持可用。

## 1. 目标与参考

以 [主菜单视觉图](../concepts/01-main-menu.png) 为气氛基准：夜间动物麻将馆、深翡翠牌桌、朱红漆木、暖金书法标题、大幅章鱼主视觉。当前页面的[改造前截图](menu-before.png)采用标题/角色/入口三列，入口偏窄、信息拥挤。新版聚合为**左侧标题与选择、右侧角色主视觉**，让首次进入时能直接找到“单机开局”。

图中手绘字和费用不可直接截图贴图。按钮、文案、焦点态、角色名及状态由 HTML/CSS/JS 绘制。

## 3. 1280×720 构图

- 顶栏约 52px，页脚可压缩为约 26px；主舞台约 640px。
- 左侧内容安全区：x≈64–650。标题在 y≈105–225，下面只留一行简短玩法说明。三张主入口各高约 74–82px，依次位于 y≈300–550；次入口横向或两行排在下方。
- 右侧主视觉区：x≈700–1260，y≈90–630。章鱼透明肖像宽约 500px，脸部是焦点，腕足可越过金框但不得进入左侧按钮命中区；底部角色牌显示“当前角色 / 特性 / 对应绝技”。
- 主入口按视觉图排列：**单机开局**（`solo-quick`）、**联机大厅**（`goto-lobby`）、**动物图鉴**（`goto-characters`）。次入口：**选择模式**（`goto-mode`）、**千术秘籍**（`goto-codex`）、**设置**（`open-settings`）。保留全部旧行动映射。
- 三张卡可分别用绿、朱红、深蓝作为底色，右缘小幅裁入熊猫/狐狸/喜鹊肖像，按钮文字保持 DOM；不要用概念图裁成按钮。
- 当前动物不是章鱼时，右侧肖像改用现有透明角色图集；角色名和特性随状态更新。章鱼大图仅在选择章鱼时显示，避免肖像与文字不一致。
- 简短“演示数据”标识保留在角落，不在主菜单大面积解释原型技术边界；详述在秘籍/图鉴或 README。

## 4. 入口从右移入

菜单整页进入或从其他页面返回时，**每张主卡与次入口从右向最终位置滑入**。入口动效属于容器，hover/focus 反馈属于内部按钮，二者用不同元素或不同 CSS 属性，避免 transform 互相覆盖。

| 元素 | 起始 | 时长 | 延迟 | 结束 |
| --- | --- | ---: | ---: | --- |
| 标题区 | 透明、上移 10px | 360ms | 0ms | 原位清晰 |
| 右侧角色 | 透明、右移 32px、缩小 3% | 600ms | 100ms | 原位，随后只允许慢速轻呼吸 |
| 主卡 1 | 透明、右移 84px | 520ms | 180ms | x=0，opacity=1 |
| 主卡 2 | 同上 | 520ms | 270ms | 同上 |
| 主卡 3 | 同上 | 520ms | 360ms | 同上 |
| 次入口 1–3 | 透明、右移 48px | 380ms | 450/510/570ms | 同上 |

曲线建议 `cubic-bezier(.16,1,.3,1)`，只动画 `transform` / `opacity`，避免 `left` 改布局。卡片进场完成后 hover 可轻微右移 4px、提亮金边；键盘焦点加 2px 清晰外框。动作期间按钮已具语义与可聚焦性，但不会因为装饰层覆盖而无法点击。

设置为“关闭动画”、系统 `prefers-reduced-motion: reduce` 时立即显示终态，菜单完全可操作。避免使用无限循环的大范围移动；灯笼/角色呼吸可慢、低幅度，且同样受减少动态效果控制。

## 6. 适配与验收

在 1280×720 检查标题与全部六个入口无需滚动可见；在 960×540 允许舞台滚动但入口、角色名称与返回不裁切；宽度小于约 900px 时改为标题→角色→主入口→次入口的纵向流，保持按钮尺寸至少 44px 高。

验收须实际截图并核对：主菜单首次进入与返回时卡片从右依次移入；减少动态效果立即显示；键盘 Tab/Enter 可进入所有六个功能，焦点明确；改选非章鱼角色后主视觉和特性同步；页面图片加载成功；主菜单之外的八屏及三种千术流程不受这次样式改动影响。
